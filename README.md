## 👋 About me

Computer Science graduate (AI and machine learning) with an MSc. I build machine learning models and full-stack web apps.

- 🧠 **Machine learning:** time-series forecasting, classification, clustering and model explainability (my MSc dissertation forecast metro passenger flows with K-Means, XGBoost, LSTM and SHAP).
- 🌐 **Web:** real-time apps and dashboards with Next.js, TypeScript and PostgreSQL.
- 🎮 **For fun:** a 2D strategy game in Godot.
